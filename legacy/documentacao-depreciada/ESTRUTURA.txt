🚀 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

1. Instalação:
   cd simulador-refatorado/src
   python3 -m http.server 8000
   # Acessar: http://localhost:8000/

2. Desenvolvimento:
   - Editar modelos: js/models/*.js
   - Editar estilos: css/*.css
   - Editar HTML: index.html
   - Editar lógica: js/main.js

3. Testes (próxima fase):
   npm install
   npm test
